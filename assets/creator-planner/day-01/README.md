# فيديو اليوم الأول

- `ward-routine-short.mp4`: مقطع عمودي 1080×1920 بطول 27 ثانية، برسوم ونصوص عربية، بلا تعليق صوتي.
- `ward-routine-cover.png`: صورة الغلاف.
- `voiceover-ar.txt`: نص التعليق الصوتي، تقسيم المشاهد، العنوان والوصف والوسوم.
- `plan.json`: فكرة جاهزة للاستيراد في مخطط المحتوى المحلي.

قبل النشر، سجّل التعليق وأضفه إلى المقطع. موضوع الفيديو نصيحة عامة لبناء عادة يومية، وليس فتوى. لم يُتحقق من رواج الموضوع في Google Trends بعد؛ راجع اهتمام جمهور القناة وبلده أولًا. لم يُرفع الفيديو إلى YouTube.

تنبيه: استيراد `plan.json` في المخطط يستبدل الخطة المحفوظة في المتصفح؛ صدّر نسخة احتياطية أولًا إذا كانت لديك أفكار محفوظة.
