حالة فحوص Devobs العامة

اعرض آخر تشغيل CI عام لفرع main، وقارنه بالتزام الفرع عند الطلب. هذه حالة الفحوص المسجلة وليست مراقبة للخدمة المستضافة أو إثبات جاهزيتها.

موقع Devobs · المعاينة الاصطناعية المجانية

فحص يدوي دون مفتاح API

بالضغط على الزر، سيتصل متصفحك مباشرة بواجهة GitHub العامة. لا تحتاج تسجيل دخول أو مفتاحًا، ولا تُرسل المذكرات المحلية أو بيانات المشاريع الخاصة. لا يوجد تحديث تلقائي.

جارٍ تجهيز القارئ؛ لم تُطلب بيانات GitHub بعد.

حد GitHub المعتاد للطلبات غير المسجلة 60 طلبًا في الساعة لكل عنوان IP، وقد يكون مشتركًا. هذا الفحص يقرأ واجهتين؛ عند بلوغ الحد لا يُعاد الطلب تلقائيًا.

فتح التشغيل العام في GitHub

يتاح ملف CloudEvents للتشغيل المنتهي المطابق لـmain ذي النتيجة المدعومة ورقم المحاولة المتحقق فقط. يحفظ التنزيل ملفًا عامًا على جهازك دون طلب API إضافي؛ الاستيراد خطوة محلية مستقلة عبر دليل المستودع.

مطابقة الالتزام ملاحظة وقت الطلب؛ قد يتغير الفرع بعدها. نجاح CI لا يثبت نشر API أو عزل العملاء أو قبول P01 وAI-9. لا تنفذ هذه الصفحة أي نشر أو إصلاح.

مركز فحوص مشاريع GitHub العامة

فحص يدوي اختياري لحالة CI العامة في أربعة مستودعات: Devobs وdevobs-saas وLiveOps-Integration وops. ينفذ متصفحك ما يصل إلى 8 طلبات GET عامة؛ لا يقرأ مستودعات خاصة ولا ينقل أسرارًا أو يشغّل إصلاحات. النجاح يخص CI فقط، وليس جاهزية الخدمة.

لم يبدأ الفحص بعد.

المشاريع الأخرى ليست متصلة بهذه الصفحة. عند بلوغ حد الطلبات أو تعذر التحقق، تظهر الحالة غير مؤكدة ولا تُخمن نتيجة نجاح.
