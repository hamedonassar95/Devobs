# دليل المساهمة في المشروع (Contributing Guide)

شكراً لاهتمامك بالمساهمة في مشروع **ServerOps Enterprise Console**! نسعى لبناء أفضل منصة مفتوحة المصدر لمراقبة الخوادم وهندسة موثوقية المواقع (SRE).

---

## 🧭 آلية العمل داخل Devobs

1. **اعمل من جذر مستودع Devobs**، مع إبقاء ملفات التطبيق داخل `apps/ai-intelligence-console/`.
2. **أنشئ فرع ميزة** وفق سياسة المستودع الأساسي:
   ```bash
   git checkout -b feat/your-feature-name
   ```
3. **تطبيق التعديلات**: احرص على اتباع معايير TypeScript و Tailwind CSS.
4. **التحقق من خلو الأخطاء**:
   ```bash
   npm run lint
   npm run build
   ```
5. **كتابة رسائل الـ Commit وفق صيغة Conventional Commits**:
   - `feat:` إضافة ميزة جديدة
   - `fix:` إصلاح خطأ أو عطل برمجي
   - `docs:` تحديث أو إضافة توثيق
   - `refactor:` إعادة صياغة كود دون تغيير في السلوك
   - `chore:` تحديث حزم أو إعدادات
6. **افتح Pull Request إلى Devobs** واشرح التغييرات والهدف منها. لا تهيئ Git داخل هذا المجلد، ولا تغيّر عنوان `origin`، ولا ترفع هذا المجلد كمستودع مستقل.

---

## 🔒 الإبلاغ عن الثغرات الأمنية (Security)
إذا اكتشفت ثغرة أمنية، يرجى عدم فتح Issue عام، بل التواصل مباشرة مع فريق العمل عبر القنوات المحددة.
