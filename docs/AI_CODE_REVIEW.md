# مراجعة الكود بمساعدة Codex

يشغّل `.github/workflows/ai-code-review.yml` مراجعة استشارية عند فتح طلب سحب
من فرع داخل مستودع Devobs أو عند تحديثه، باستثناء طلبات Dependabot. يركز Codex
على فرق التغيير ويقرأ السياق المرتبط عند الحاجة، ثم يحدّث تعليقًا واحدًا تابعًا
لـGitHub Actions بحالة المراجعة ونتيجتها لكل تشغيل غير ملغى. لا يوافق على طلب
السحب ولا يدمجه.

## الإعداد والتكلفة

- يتطلب سر GitHub Actions باسم `OPENAI_API_KEY` من صفحة
  **Settings → Secrets and variables → Actions**. لا يكفي `GITHUB_TOKEN`؛ فهو
  مخصص لوصول محدود إلى GitHub وليس لمصادقة OpenAI.
- كل مراجعة ناجحة ترسل بيانات الكود اللازمة للتحليل إلى OpenAI وتُحاسب وفق
  حساب API لدى OpenAI. لم يُضبط مفتاح أو حد مالي بواسطة هذا المستودع. عند
  غياب السر، لا يستدعي المسار النموذج ويحدّث التعليق بحالة التخطي.
- طلبات السحب القادمة من fork تُتخطى عمدًا كي لا يُتاح سر API لكود خارجي.
  وطلبات Dependabot مستثناة لتفادي تشغيل مدفوع بمفتاح API غير متاح لعمليات
  Dependabot. لا تستخدم `pull_request_target` لتجاوز هذه القيود.
- لا يمكن التحقق من وجود السر أو رصيد الحساب من ملفات Git؛ يلزم التأكد من
  إعداد المستودع وحساب OpenAI قبل اعتبار المراجعة مفعّلة.

## حدود الصلاحيات

- يستخدم Codex Action الرسمي من OpenAI المثبّت على commit ثابت، وإصدار Codex
  CLI محدد، مع ملف صلاحيات للقراءة فقط. يعطّل تحميل تعليمات المشروع
  (`AGENTS.md` والملفات الاحتياطية) حتى لا تتحكم تعليمات أضافها طلب السحب في
  المراجع. يطلب التوجيه عدم تشغيل ملفات المشروع أو تثبيت اعتماديات؛ ويمنع ملف
  الصلاحيات كتابة الملفات ووصول النموذج المباشر إلى الشبكة. الاتصال المطلوب
  بواجهة OpenAI يمر عبر الإجراء.
- مهمة المراجعة تملك صلاحيات GitHub للقراءة فقط. مهمة منفصلة ذات صلاحية
  `pull-requests: write` تنشر النتيجة الاستشارية، من دون تمرير مفتاح OpenAI
  إليها.
- تُعامل ملفات المستودع ورسائل commits كبيانات غير موثوقة؛ لا تتبع تعليمات
  موجودة بداخلها. يتم تحديث التعليق حتى عند غياب المفتاح أو فشل المراجع كي لا
  تبقى نتيجة قديمة معروضة على أنها تخص آخر تغيير. يُحدّث سير العمل تعليق
  `github-actions[bot]` فقط، ويتجاهل التعليقات التي أنشأها مستخدمون آخرون.
  تبقى النتيجة قابلة للخطأ وتحتاج مراجعة بشرية.
- لا تجعل هذه المراجعة شرط دمج إلزاميًا. استخدم نتائج CI والاختبارات وفحوص
  الأمان ومراجعة maintainer لاتخاذ قرار الدمج.

## التحقق التشغيلي

تحقق من **Actions → AI Code Review** بعد إعداد السر. يجب أن يكتمل استدعاء
Codex لطلب سحب داخلي غير تابع لـDependabot، ويظهر تعليق واحد من
`github-actions[bot]` يحمل SHA الحالي. عند غياب السر أو فشل المراجعة، يوضح
التعليق ذلك صراحة ولا يعرض نتائج المراجعة السابقة على أنها حديثة. طلبات fork
وDependabot مستثناة ولا تثبت نجاح استدعاء النموذج.

فحوص ShellCheck وCI وإعداد Dependabot موجودة بالفعل؛ راجع
[`docs/GITHUB_PAGES_DEVOPS_ROADMAP.md`](GITHUB_PAGES_DEVOPS_ROADMAP.md) بدل
إضافة نسخ مكررة منها.
