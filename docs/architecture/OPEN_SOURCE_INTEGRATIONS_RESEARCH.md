## 1. Decision rules

1. Prefer existing pinned capabilities over adding a second scanner, bot, service, or control plane.
2. Treat permissive licenses as permissible only with attribution/no-warranty caveats; treat AGPL, BUSL, SSPL, RSAL, GPL, LGPL, and unknown rules licenses as requiring explicit owner review.
3. Do not infer commercial support, SLA, or production readiness from an OSS license or a repository pin.
4. Do not install, upgrade, or run any candidate in this task. Version facts are from official release pages/feeds at research time, not from a local install.
5. Do not add paid inference, hosted services, cloud resources, cluster controllers, or network-dependent checks.

`Cx`, cost, and testability estimates are **ASSUMED engineering judgments**, not measured production results. Source, license, and release facts are **VERIFIED** from the linked official sources unless marked otherwise.

## 4. Official command syntax evidence

- The repository runs `python -m compileall -q <path>`. The official [Python `compileall` documentation](https://docs.python.org/3/library/compileall.html) states: “This module can work as a script (using `python -m compileall`) to compile Python sources” and `-q` means “Do not print the list of files compiled.”
- Tests use the repository's `unittest` convention. The official [Python `unittest` documentation](https://docs.python.org/3/library/unittest.html) documents `python -m unittest discover -s <directory> -p <pattern>` and states discovery turns paths into importable module names.
- Draft PR handoff uses the officially documented [`gh pr create`](https://cli.github.com/manual/gh_pr_create) flags `--draft`, `--base`, `--head`, `--title`, and `--body-file`. `gh` is unavailable in this workspace, so no PR was created here.
- Dependabot SHA-pin limitation is quoted from the official [Dependabot alerts documentation](https://docs.github.com/en/code-security/dependabot/dependabot-alerts/about-dependabot-alerts), not inferred from the local config.
