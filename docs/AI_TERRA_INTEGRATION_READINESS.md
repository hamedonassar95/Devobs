## Terra: ما تثبته الوثائق الرسمية

- **VERIFIED — OpenAI API:** صفحة [GPT-6.1 Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra) تعرض model ID `gpt-6.1-terra` وتدعم `v1/responses` و`v1/chat/completions`؛ وتقول إن tool calling يتطلب Responses API. ودليل [Responses API](https://developers.openai.com/api/docs/guides/migrate-to-responses) يوصي بها للمشاريع الجديدة. لمسار استشاري بلا أدوات، Responses API ملائمة كواجهة مستقبلية محتملة؛ لا يلزم نسخ أمر `curl` أو تفعيل عميل الآن.
- **VERIFIED — بيانات OpenAI API:** يمكن إرسال `store: false` لعدم حفظ كائن الاستجابة عبر API، لكن [دليل البيانات](https://developers.openai.com/api/docs/guides/your-data) يذكر أن سجلات مراقبة إساءة الاستخدام قد تحتوي prompts/responses وبيانات مشتقة. هذا الخيار ليس ضمانًا شاملًا لعدم الاحتفاظ ولا ينطبق تلقائيًا على GitHub Copilot.
- **VERIFIED — تسعير OpenAI API المنشور وقت الفحص:** صفحة النموذج تعرض لكل مليون token: إدخال `$1`، إدخال مخبأ `$0.05`، كتابة cache لمدة 30 دقيقة `$1.25`، ومخرج `$5`. وتذكر مضاعفات للسياق فوق 272K، ورسومًا لبعض الأدوات ووضع Fast والمعالجة الإقليمية. هذه أسعار API المنشورة وليست ميزانية أو سقف إنفاق لحساب Devobs.
- **VERIFIED — Copilot:** إعلان [GitHub بتاريخ 2026-10-26](https://github.blog/changelog/2026-10-26-gpt-6-1-terra-in-github-copilot/) يذكر توفر Terra ضمن خطط Copilot متعددة، ومنها Copilot CLI، وفوترة استخدام بأسعار المزوّد؛ كما يذكر سياسة النموذج لإداريي Business/Enterprise. هذا لا يثبت أهلية حساب Devobs أو أن نسخة العميل المثبتة تدعم model ID.
