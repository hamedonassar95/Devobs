# دليل وجهات تكامل البيانات في Devobs

## الحالة والمصدر

استُخرجت هذه القائمة من النص التسويقي الذي قدّمه مالك المشروع بتاريخ 2026-10-10 بتوقيت عمّان.
هذه إضافة توثيقية للتخطيط؛ لا تثبّت أدوات ولا تربط حسابات ولا تفعّل نقل بيانات.
اسم مزوّد الخدمة ورابطه غير مذكورين. جميع أوصاف الوجهات أدناه من النص المرسل، ولم يتم التحقق منها لدى المزوّد.

النص يسرد **13 وجهة** لاستقبال البيانات أو استخدامها، وليس أسماء مصادر البيانات الستين.
الحديث عن سعر موحد وحسابات واستعلامات غير محدودة وأكثر من 60 مصدرًا هو ادعاء في العرض المرسل، وليس ميزة مثبتة في Devobs أو اشتراكًا تم تفعيله.

## المعلومات المطلوبة للتفعيل

1. رابط مزوّد العرض ووثائق التكامل الرسمية.
2. قائمة مصادر البيانات الفعلية التي يدعمها، وتحديد المصدر المطلوب ربطه أولًا.
3. تأكيد الحساب والخطة المتاحة لدى المزوّد وتكلفة الاستخدام وحدوده.
4. تحديد وجهة أولى وحساب تجريبي وحقول البيانات المطلوبة.
5. الحصول على إعدادات الاتصال والصلاحيات من وثائق المزوّد؛ لا تُخمن روابط API أو MCP.

## مسار تنفيذ مقترح بعد استكمال المعلومات

- اختيار مصدر واحد ووجهة واحدة لتجربة صغيرة قابلة للتحقق.
- توثيق خريطة الحقول والتحديثات المتوقعة وآلية المصادقة.
- حفظ الأسرار في مدير أسرار مناسب لبيئة التنفيذ وفق [سياسة الأمان](../SECURITY.md)، وعدم وضعها في الملفات أو الواجهة العامة.
- تجهيز إعداد التكامل في فرع مستقل، ثم التحقق من نجاح المصادقة وصحة البيانات ومعالجة الفشل.
- تسجيل نتيجة الاختبار وتكلفته؛ لا توصف الوجهة بأنها مفعّلة قبل نجاح اختبار اتصال فعلي.
- توسيع التكاملات تدريجيًا وفق حاجة خدمات Devobs وعملائه.

إضافة هذا الدليل إلى GitHub لا تنشئ اشتراكات لدى الخدمات المذكورة ولا تمنح الوصول إلى حسابات العملاء.
