# Devobs بالموارد المجانية المتاحة

## الاستخدام الآن

[افتح المعاينة المجانية](https://hamedonassar95.github.io/Devobs/assets/free-devobs/).
تعرض نتائج فعلية للمحركات المحلية AI-1 إلى AI-7 على **عينة اصطناعية ثابتة**
من حالات الاختبار المعلنة. يمكنك تنزيل JSON وكتابة مذكرات محلية والبحث فيها
وتثبيتها وأرشفتها واستعادتها. المذكرات في متصفحك فقط؛ لا تكتب أسرارًا أو بيانات عملاء.
المعاينة لا تستقبل سجلاتك ولا تتصل بخوادم أو حسابات أو نماذج سحابية.

| المورد | الاستخدام والحدود |
| --- | --- |
| GitHub Pages الحالي | نشر ملفات المعاينة الثابتة داخل المستودع العام. لا يحتاج قاعدة بيانات أو مفتاح API. |
| GitHub Actions الحالي | الفحوص والنشر عبر المهام القائمة وUbuntu القياسي؛ لم تُضف مهمة دورية أو runner مدفوع. |
| Node.js المحلي | تشغيل مسار التحليل الاسترشادي دون حساب أو مفتاح أو استدلال مدفوع، عند توفر جهاز. |

المستودع عام وPages مفعّل، وفق فحص GitHub في 2026-11-15. تؤكد
[وثائق Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages)
إتاحته للمستودعات العامة على GitHub Free، وتوضح
[فوترة Actions](https://docs.github.com/en/billing/concepts/product-billing/github-actions)
إعفاء runners القياسية للمستودعات العامة؛ runners الكبيرة لها فوترة مختلفة.
تظل حصص الخدمة وسياساتها سارية. هذا لا ينشئ اشتراكًا أو حد فاتورة جديدًا.

## التشغيل المحلي دون مفاتيح

من جذر المستودع، مع Node.js 24 وPython 3:

```sh
node scripts/local_advisory_acceptance.mjs
python3 scripts/stage_site.py --source-sha "$(git rev-parse HEAD)"
python3 -m http.server 8000 --bind 127.0.0.1 --directory _site
```

افتح `http://127.0.0.1:8000/assets/free-devobs/`؛ أوقف خادم الملفات بـCtrl+C.
الأمر الأول ينفذ المسار المحلي على العينة ثم يغلق خادمه المؤقت تلقائيًا.
لتشغيل المحركات على عينات اصطناعية أخرى، اتبع [دليل اللوحة المحلية](AI_LOCAL_DASHBOARD.md).
لتجديد العينة العامة من المصدر المراجع فقط:

```sh
node scripts/free_demo_snapshot.mjs > assets/free-devobs/snapshot.json
node --test tests/free_static_demo.test.mjs
```

اختبار التجديد يقارن الملف المنشور بمخرجات المحركات الحالية، كي لا تنفصل
المعاينة عن الشيفرة. لا تستبدل حالات الاختبار العامة ببيانات خاصة.
النسخ المشترك للأصول في `stage_site.py` يخدم CI وPages ومسارات الاستعادة القائمة؛
لا ينفذ شيفرة المرشح أثناء التجهيز. صورة Docker تنسخ قائمة ملفات عامة محددة فقط.

## حدود الموارد الأخرى

فحص Render في 2026-11-15 أظهر خدمة Free في Frankfurt والنشر التلقائي متوقفًا،
وقاعدة Free متاحة تنتهي في **2026-12-05**. لم تُنشأ موارد أو تُرقّ خطة أو تتغير
أسرار أو إعدادات. المعاينة مستقلة عنهما ولا تعتبرهما API أو تخزينًا دائمًا.
راجع [حدود Render Free](https://render.com/docs/free) و[قرار الميزانية](P01_RENDER_BUDGET_ENVELOPE.md).

الإنتاج المستضاف، والهوية الحية وعزل العملاء والاستعادة المستضافة وإنفاذ الإنفاق
وتقييم AI-9 ببيانات مستقلة ما زالت متطلبات منفصلة. P01 يبقى NO-GO/BLOCKED،
وAI-9 BLOCKED، وقبول Codex runtime OPEN. المعاينة المجانية ليست دليل قبول إنتاجي.
