# AI-2: كشف الشذوذ المحلي

**الحالة:** نموذج إحصائي محلي أولي على فرع AI-2؛ ليس مراقبة حية ولا خدمة إنتاجية.

## الهدف والنطاق

تحليل أحداث `server_metric` المخزنة محليًا وفق مخطط AI-1، وإظهار **مرشحات شذوذ** قابلة للتفسير. لا يجمع بيانات، ولا يتصل بالشبكة، ولا يكتب على سجل الأحداث، ولا يرسل تنبيهًا أو يصلح شيئًا. الإدخال الاصطناعي هو أساس التحقق الحالي.

## الخوارزميات والافتراضات

يحلل البرنامج أحدث نقطة لكل مقياس مقارنةً بما يصل إلى 30 نقطة سابقة، ويحتاج ست نقاط على الأقل (خمس في baseline وأحدث نقطة). يخرج:

- `z_score`: انحراف مطلق قدره 3 أو أكثر عن متوسط وانحراف معياري للعينة السابقة.
- `moving_average`: تغير مطلق يبلغ 30% من المتوسط السابق أو الحد المطلق الأدنى (0.5 نقطة مئوية للمقاييس النسبية، أو `0.000001` لغيرها).
- `ewma`: متوسط أسي سابق بـ`alpha=0.3`؛ إشارة عند تجاوز ثلاثة انحرافات معيارية موزونة أو الحد الأدنى.
- `error_rate_spike`: زيادة موجبة في `error_rate` تتجاوز الأكبر بين ثلاثة انحرافات معيارية ونقطة مئوية واحدة.

هذه عتبات ابتدائية **ASSUMED** وليست مُعايرة على بيانات إنتاج. لا توجد موسمية أو مقارنة بين مضيفين أو تقدير دقة/استرجاع. `anomaly_candidate` إشارة تستلزم مراجعة بشرية، لا استنتاج سبب أو حادث مؤكد. عند نقص التاريخ يظهر `insufficient_data`؛ ومع تباين صفري لا يُحسب z-score.

## تشغيل محلي

أدخل أحداثًا اصطناعية أولًا باستخدام [دليل AI-1](AI_EVENT_INGESTION.md)، ثم اقرأ سجلًا محليًا فقط:

```sh
node scripts/ai_intelligence/anomaly_report.mjs --store /path/to/devobs-events.jsonl
```

يستخدم الأمر حدّ حجم سجل AI-1 وصلاحيات القراءة الموجودة فيه، ويطبع تقرير JSON إلى stdout دون كتابة الملف. الأخطاء رموز ثابتة لا تتضمن المسار. لا تشغله على بيانات حقيقية قبل سياسة خصوصية واحتفاظ وموافقة منفصلة.

## الفحوص والحدود

```sh
node --check scripts/ai_intelligence/anomaly_detector.mjs
node --check scripts/ai_intelligence/anomaly_report.mjs
node --check tests/ai_anomaly_detector.test.mjs
node --test tests/ai_anomaly_detector.test.mjs
```

الاختبارات تستخدم مقاييس اصطناعية وملفات مؤقتة بلا اتصال خارجي. لا توجد اعتماديات جديدة أو استدلال LLM. لا يثبت هذا النموذج خلو النظام من أعطال، ولا يبرر تشغيل تنبيهات أو إصلاحات تلقائية. معايرة العتبات وقياس false positives على مجموعة مُصرّح بها خطوة لاحقة مستقلة قبل الاعتماد.
