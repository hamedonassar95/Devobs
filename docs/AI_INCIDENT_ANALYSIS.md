# AI-3: تجميع السجلات وربط سياق CI

**الحالة:** نموذج محلي أولي على بيانات اصطناعية؛ لا يثبت سببًا جذريًا ولا يستخدم سجلات تشغيل حقيقية.

## النطاق والطريقة

يقرأ التقرير سجل AI-1 المحلي، ويحلل أحداث `log` فقط. يطبع بصمات SHA-256 مختصرة لقوالب بعد تطبيع الأرقام والمعرفات، ثم يجمع السجلات المتقاربة باستخدام TF-IDF وcosine similarity بحد أولي **ASSUMED** مقداره 0.62. التحليل محصور بـ250 سجلًا و10,000 حدث لكل تشغيل و128 token لكل رسالة، ويرفض ما يتجاوزها، ولا يعرض نص الرسالة الخام.

تستخرج قواعد ثابتة مؤشرات مثل timeout وDNS ورفض الاتصال والصلاحيات والذاكرة. تعرضها كـ`POSSIBLE` مع تحقق تالٍ ودرجة `low` أو `medium` heuristic؛ هذه ليست احتمالات معايرة ولا نتيجة مؤكدة. عند غياب marker تبقى الفرضيات فارغة.

يربط التقرير فقط أحداث `ci_result` السابقة ضمن نافذة ست ساعات، أو SHA كاملًا مذكورًا صراحة في نص السجل، كـ**سياق محتمل**. هذا لا يثبت السببية. مخطط الأحداث الحالي لا يحتوي حدث نشر؛ لذلك ارتباط النشر غير مدعوم ويظهر `unsupported_by_event_schema`.

## تشغيل محلي

```sh
node scripts/ai_intelligence/incident_report.mjs --store /path/to/devobs-events.jsonl
```

القراءة محلية فقط ولا تعدّل السجل أو تتصل بالشبكة. استخدم البيانات الاصطناعية فقط حتى اعتماد سياسة الخصوصية والاحتفاظ والحذف. لا تُرسل التقارير إلى LLM ولا تنفذ التوصيات تلقائيًا.

## الفحوص والحدود

```sh
node --check scripts/ai_intelligence/incident_analysis.mjs
node --check scripts/ai_intelligence/incident_report.mjs
node --check tests/ai_incident_analysis.test.mjs
node --test tests/ai_incident_analysis.test.mjs
```

التجميع greedy حسب الترتيب الزمني ويمثل كل مجموعة أول سجل فيها؛ قد يفوت أوجه تشابه غير مباشرة. لا يوجد TF-IDF مدرّب أو تقييم precision/recall، ولا دعم لربط النشر. مخرجات السبب الجذري اقتراحات تفسيرية لمراجعة بشرية، لا تشخيص أعطال أو إذن تغيير.
