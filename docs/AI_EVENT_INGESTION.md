# استقبال أحداث AI-1 محليًا

**الحالة:** تنفيذ محلي أولي، لا يساوي جاهزية إنتاجية أو ذكاءً اصطناعيًا مكتملًا.

## النطاق

يوحّد هذا المكوّن أحداثًا محضّرة محليًا من السجلات، والحوادث، ونتائج CI، ومقاييس الخادم في سجل JSONL محلي. يستخدم Node.js وواجهات النظام المدمجة فقط: لا حزم جديدة، ولا اتصالات شبكة، ولا API، ولا مفاتيح، ولا اشتراك أو استدلال LLM. لا يسحب البيانات من GitHub أو GitLab أو الخوادم؛ على المالك تجهيز ملف JSONL بعد مراجعة البيانات والموافقة على استخدامها.

هذا أساس جمع/تطبيع بيانات AI-1 فقط. لا يتضمن كشف الشذوذ أو تحليل السبب الجذري أو التوصيات أو واجهة/API أو الربط مع جامعات Python الموجودة. لا يُدّعى أن قواعد حجب النصوص تكتشف كل الأسرار أو تُغني عن تقليل البيانات ومراجعتها.

## مخطط الحدث

كل سطر إدخال كائن JSON مستقل، والمخطط الإصدار 1 يفرض الحقول التالية دون حقول إضافية:

| الحقل | المعنى |
|---|---|
| `schema_version` | العدد `1` |
| `occurred_at` | وقت ISO-8601 يتضمن منطقة زمنية؛ يُحوّل إلى UTC |
| `source` | `application` أو `github_actions` أو `gitlab_ci` أو `server` أو `operator` |
| `kind` | `log` أو `incident` أو `ci_result` أو `server_metric` |
| `severity` | `debug` أو `info` أو `warning` أو `error` أو `critical` أو `unknown` |
| `data` | حقول محددة بحسب النوع ومتحقق منها بدقة |

أمثلة الحقول داخل `data`:

- `log`: `stream`, `message`؛ النص حتى 2,000 حرف.
- `incident`: `summary`, `status`, `impact`؛ لا أسماء أشخاص أو تفاصيل عميل.
- `ci_result`: `workflow`, `job`, `conclusion`, `commit_sha`؛ SHA كامل من 40 خانة أو `null`.
- `server_metric`: اسم مقياس من قائمة ثابتة، قيمة رقمية غير سالبة، ووحدة مطابقة؛ النسب لا تتجاوز 100.

مثال اصطناعي غير حساس:

```json
{"schema_version":1,"occurred_at":"2026-10-28T08:15:00Z","source":"server","kind":"server_metric","severity":"info","data":{"name":"cpu_percent","value":23.5,"unit":"percent"}}
```

ينشأ `event_id` حتمي محليًا من SHA-256 للمحتوى المطبّع. تُرفض الدفعة كلها إذا احتوى أي سطر على JSON غير صالح، أو مفاتيح مكررة، أو بنية/مصدر/نوع/قيمة غير مدعومة. الأحداث المكررة تُهمل دون إعادة كتابة الملف إن لم توجد إضافات.

## تشغيل محلي

استخدم بيانات اصطناعية فقط إلى أن توجد سياسة منفصلة معتمدة للبيانات الحقيقية:

```sh
node scripts/ai_intelligence/event_ingest.mjs --input /path/to/synthetic-events.jsonl --store /path/to/devobs-events.jsonl
```

يمكن استعمال `--input -` للقراءة من stdin غير التفاعلي. يجب تحديد `--store` صراحة، وهو ملف محلي لا يقبل `-`. الحدود الحالية: 1 MiB لملف الإدخال، و100 حدث للدفعة، و50 MiB للسجل. المخرجات تعرض أعداد المقبول والمكرر فقط؛ رسائل الخطأ رموز ثابتة ولا تعرض محتوى الأحداث أو المسارات.

يُنشأ ملف السجل بصلاحيات مستخدم محلية `0600`، والمجلد الجديد `0700`، مع كتابة ذرية وقفل يمنع كاتبين متزامنين. تُرفض الروابط الرمزية، والسجل الموجود بصلاحيات أوسع من المالك، والسجل غير السليم. إذا بقي ملف `.lock` بعد توقف مفاجئ، تحقّق يدويًا من عدم وجود كاتب نشط قبل تنظيفه. الحماية تعتمد على صلاحيات نظام الملفات المحلي؛ التخزين غير مشفر ولا يحمي من مسؤول النظام أو نسخ احتياطي غير آمن.

## الفحوص والحدود

```sh
node --check scripts/ai_intelligence/event_schema.mjs
node --check scripts/ai_intelligence/event_ingest.mjs
node --check tests/ai_event_ingest.test.mjs
node --test tests/incident_guard.test.cjs tests/ai_event_ingest.test.mjs
```

الاختبارات تستخدم ملفات مؤقتة وبيانات اصطناعية ولا تتصل بالشبكة. لا يوجد في المستودع إعداد `package.json` أو أوامر ESLint/TypeScript؛ لذلك فحص `lint` و`typecheck` غير متاحين لهذا المكوّن حاليًا، و`node --check` فحص صياغة وليس lint أو typecheck.

**غير منفّذ بعد:** ربط مصادر حية، تخزين SQLite، تشفير، سياسة احتفاظ/حذف، تقييم جودة بيانات الإنتاج، أو مراحل AI-2 إلى AI-7. يجب مراجعة خصوصية البيانات والموافقة على أي موصل أو بيانات غير اصطناعية في مهمة مستقلة قبل التنفيذ.
