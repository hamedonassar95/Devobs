# تغذية راجعة محلية للتوصيات — AI-6

**الحالة: تجربة محلية اختيارية؛ ليست تعلّمًا آليًا مُعايرًا ولا دليلًا على صحة السبب.** يسجل الأمر قبولًا أو رفضًا صريحًا من المشغّل لتوصية واحدة. لا يرسل بيانات، ولا ينفذ إصلاحًا، ولا يغيّر درجة AI-3 الاحتمالية.

## الاستخدام

أنشئ مجلدًا خاصًا خارج المستودع، ثم شغّل تقرير AI-4 كالمعتاد. يعرض كل اقتراح `feedback_key` مجزّأً. لعرض السجل وترتيب المراجعة بحسبه:

```sh
node scripts/ai_intelligence/recommendation_report.mjs --store <local-jsonl-file> --feedback-ledger <private-jsonl-file>
```

لتسجيل قرار بشري صريح، استخدم مفتاح التوصية الظاهر في التقرير:

```sh
node scripts/ai_intelligence/recommendation_report.mjs --store <local-jsonl-file> --feedback-ledger <private-jsonl-file> --record-feedback <sha256-key> --decision accepted
```

استبدل `accepted` بـ`rejected` عند الرفض. التسجيل لا يحدث إلا بوجود `--record-feedback` وقرار صالح؛ تمرير السجل للقراءة وحدها لا يكتب. يجب أن يكون مجلد السجل موجودًا، ينشأ الملف بصلاحية المالك فقط، ويرفض الأمر الروابط الرمزية والسجل غير الخاص أو غير الصالح. لا يخزن السجل تعليقات أو نص الحادث أو أسماء أشخاص؛ يحتوي معرفًا مشتقًا مجزّأً، فئة سبب ثابتة، القرار ووقته. الملف غير مشفر تلقائيًا؛ لا تضعه داخل Git أو في مجلد مشترك، واحذف السجل عند انتهاء الحاجة إليه.

## كيف يؤثر القرار

- تُحسب الإحصاءات حسب فئة سبب محددة، مع احتساب أحدث قرار فقط لكل مفتاح توصية؛ إعادة التقرير أو إعادة القرار نفسه لا تضاعف وزن التوصية.
- المعدل المعروض هو `(القبول + 1) / (القرارات + 2)`، وهو متوسط مبسّط بانحياز ابتدائي متعادل. لا يمثل احتمال صحة التوصية أو ثقة إحصائية.
- لا يُعاد ترتيب المجموعة إلا بعد ثلاث توصيات مختلفة على الأقل للفئة نفسها. عندها تتقدم الفئات المؤهلة مرتبةً بهذا المعدل؛ وتبقى الفئات الأقل بيانات بترتيبها الأساسي بعدها.
- التفضيل البشري قد يعكس ملاءمة السياق لا صحة تشخيص السبب؛ لذلك تظل المخرجات اقتراحًا للمراجعة فقط، ولا تغيّر `heuristic_signal` أو تصنّف فرضية على أنها مؤكدة.

الواجهة تستخدم مكتبات Node المدمجة فقط: [واجهات نظام الملفات](https://nodejs.org/api/fs.html) و[مشغّل الاختبارات](https://nodejs.org/api/test.html). الاختبارات بيانات اصطناعية، ولا تختبر بيانات تشغيل حقيقية أو دقة مستقبلية.
