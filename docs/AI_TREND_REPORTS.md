# تقارير الاتجاهات المحلية — AI-5

**الحالة: نموذج محلي استرشادي؛ ليس مراقبة إنتاجية أو تنبؤًا مُعايرًا.** يعمل على سجل أحداث JSONL موجود ويطبع تقرير Markdown إلى stdout. لا يقرأ سجلات GitHub أو الخوادم تلقائيًا، ولا يكتب في السجل، ولا يتصل بالشبكة.

## التشغيل

من جذر المستودع:

```sh
node scripts/ai_intelligence/trend_report.mjs --store <local-jsonl-file>
node --test tests/ai_trend_forecast.test.mjs
```

يُنتج التقرير ملخصًا لآخر يوم UTC ممثل في السجل، ونافذة السبعة أيام المنتهية بذلك اليوم. يعرض أعداد الأنواع والشدة وإحصاءات المقاييس فقط؛ لا يعرض نصوص السجل أو معرّفات الأحداث أو مسار الملف. إذا كان السجل فارغًا، يصرّح بذلك ولا ينشئ توقعًا.

## طريقة الاستقراء وحدوده

- تُجمع عينات كل مقياس في متوسط يوم UTC. يستخدم الانحدار الخطي أقل المربعات لاستقراء خطوة يوم واحد.
- يستخدم التمهيد الأسي البسيط α=0.3 ثابتًا؛ لا يجري تحسينًا للمعامل أو اختيار نموذج تلقائيًا.
- لا يصدر المرشح إلا عند توفر ستة أيام UTC متصلة على الأقل، وبحد أقصى آخر 30 يومًا متصلًا. الفجوات تؤدي إلى `insufficient_history` بدل ملء بيانات مفقودة.
- القيم المئوية المتوقعة خارج 0–100 تُعرض مع `range_warning` ولا تُقصّ. كل القيم استرشادية بلا فواصل ثقة أو اختبار رجعي أو معايرة.
- لا تثبت الاتجاهات حادثًا أو سببًا أو حالة مستقبلية، ولا تنشئ تنبيهًا أو توصية تنفيذية.

الصيغ تستند إلى [Forecasting: Principles and Practice — الانحدار بأقل المربعات](https://otexts.com/fpp3/least-squares.html) و[التمهيد الأسي](https://otexts.com/fpp3/exponential-smoothing.html). يوضح المرجع أن التمهيد الأسي البسيط يلائم سلسلة بلا اتجاه أو موسمية واضحة؛ لذلك تُعرض قيمته جنبًا إلى جنب مع الاتجاه الخطي ولا يُفترض أنه الأنسب لكل سلسلة. تُنفّذ الحسابات هنا محليًا في Node دون مكتبات إضافية.

تُشغّل الاختبارات عبر مشغّل Node المدمج الموثق في [Node.js Test Runner](https://nodejs.org/api/test.html). تغطي الحالات بيانات اصطناعية فقط؛ لا توجد نتائج دقة حقيقية أو ادعاء امتثال.
