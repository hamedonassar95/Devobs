# مراجعة Free Claude Code وملاءمته لـDevobs

## القرار

المشروع أداة محلية لتوجيه نماذج الذكاء الاصطناعي إلى عدة وكلاء برمجة. قد تفيد
المطور الذي يريد تجربة مزوّدات أو نماذج متعددة على جهازه. لا حاجة لإضافة
تطبيقها أو اعتمادياتها إلى Devobs: المستودع الحالي موقع GitHub Pages ثابت
ويستخدم GitHub Actions وAI DevKit لسير العمل، بينما Free Claude Code تطبيق
مستقل بواجهة إدارية وخدمة وكيل محلية.

أضفنا هذا التقييم كمرجع اختياري فقط. لا يفعّل أي مزوّد أو مفتاح أو إجراء في
GitHub Actions، ولا يغيّر النشر أو صلاحيات المستودع.

## ما يقدمه المصدر

بحسب README للمشروع، يجمع واجهة لاختيار المزوّد والنموذج، ويربط عدداً من وكلاء
البرمجة، ويسمح بترتيب نماذج احتياطية. قد ينتقل الطلب الاحتياطي إلى مزوّد آخر
ويستهلك حصة أو رصيداً إضافياً. الأعداد والعبارات التسويقية عن المزوّدات أو
الحصص المجانية هي ادعاءات من المشروع؛ التوفّر والحدود وشروط الاستخدام يحددها
كل مزوّد وقد تتغير. ويصف المصدر نفسه بأنه مشروع مستقل غير تابع لـAnthropic.

المصدر الذي تمت مراجعته هو commit
[`ec10cafdb0aaea86b135c5724ffd00394d385739`](https://github.com/Alishahryar1/free-claude-code/commit/ec10cafdb0aaea86b135c5724ffd00394d385739)
بتاريخ 17 أكتوبر 2026. شملت المراجعة README والترخيص وسير عمل الاختبارات
وسياسة إصدارات Python، ولم تتضمن تثبيت التطبيق أو تشغيل شيفرته أو تدقيقاً
أمنياً كاملاً للمستودع.

## ملاءمته لـDevobs

| المجال | ما وجدناه في Devobs | القرار |
| --- | --- | --- |
| التطوير بمساعدة AI | يوجد إعداد AI DevKit ومهارات مراجعة وتنفيذ محلية | أداة خارجية اختيارية للمطور، وليست شرطاً للمساهمة |
| التحقيق الآلي | توجد مسارات GitHub Actions منفصلة مع فحوص صلاحيات واعتماد بشري | لا تستبدل المحقق ولا تضفها كخطوة تلقائية للحوادث |
| CI/CD | يستخدم CI فحوصاً متوازية، صلاحيات محدودة، وتثبيتاً لإجراءات GitHub على SHA | الضوابط الأساسية موجودة؛ لا ننسخ سير عمل المشروع الآخر |
| الاختبارات | للمصدر اختبارات Python وPlaywright موزعة على shards | نعيد تقييم التقسيم إذا أثبت قياس CI وجود حاجة؛ لا نضيف تعقيداً بلا قياس |
| الإصدارات | المصدر حزمة Python ذات سياسة لإصدارات الإصدار | لا ينطبق على موقع Pages ووحدات Devobs الحالية |

## ضوابط تجربة محلية

إذا أراد أحد المساهمين تجربتها، فليستخدم مجلداً تجريبياً بلا أسرار أو بيانات
حساسة، ويراجع نسخة المُثبّت وإعدادات الوكلاء قبل التشغيل. يذكر المصدر أوامر
تثبيت تنفذ شيفرة محمّلة مباشرة من الإنترنت؛ لا نضيف هذا الأسلوب إلى CI ولا
نشغله على جهاز نشر. راجع خصوصية المزوّد وشروطه قبل إرسال شيفرة أو سياق إليه،
واضبط المصادقة إذا أتيح الوصول إلى الوكيل من خارج الجهاز المحلي. لا تحفظ مفاتيح
المزوّد في هذا المستودع أو في سجلات التشغيل.

يذكر ملف `LICENSE` في المصدر ترخيص `AGPL-3.0-only`، بينما لا يصنفه سجل GitHub
بـSPDX محدد. لذلك لم ننسخ شيفرة أو صوراً أو ملفات إعداد منه. يلزم التحقق من
الترخيص ومتطلباته قبل أي تضمين أو تعديل مستقبلي.
