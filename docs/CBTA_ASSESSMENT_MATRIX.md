# مصفوفة CBTA وأدلة التقييم

استخدم هذه المصفوفة مع [إطار CBTA](CBTA_FRAMEWORK.md). يقيّم المقيم المستوى لكل مجال على حدة. لا يُستخدم التقييم لمنح صلاحيات مستودع أو AWS تلقائيًا.

## مصفوفة الكفاءات

| المجال | التمرين القابل للملاحظة | دليل التقييم | معيار L2 — مستقل ضمن النطاق |
| --- | --- | --- | --- |
| Git وPull Request | ينشئ فرعًا وتغييرًا محدودًا، يفتح PR واضحًا، ويرد على مراجعة. | رابط PR وموجز التغيير والمراجعة. | يربط السبب بالتغيير، يحافظ على الفحوص، ويعالج الملاحظات دون تعديل خارج النطاق. |
| CI | يفسر نتيجة validate في PR تجريبي أو تشغيل سابق، ويحدد أول خطوة تشخيصية. | رابط التشغيل أو شرح موثق للخطوات والنتيجة. | يحدد الفحص الفاشل والدليل المرتبط به، يصلح السبب أو يصعّد، ولا يتجاوز الفحص المطلوب. |
| أمن الأتمتة | يراجع Workflow لتحديد الصلاحيات والأسرار ومصدر الإجراءات وحدود الثقة. | قائمة مراجعة مرتبطة بملف محدد أو PR. | يميز متغيرات الإعداد عن السر، يطلب أقل صلاحية، يحدد أين يجب تثبيت الإجراء، ولا يضع قيمة سرية في سجل أو artifact. |
| Ansible والحالة المطلوبة | يشغّل تمرين localhost، يراجع التغيير المتوقع، يطبق الحالة، ثم يعيد التشغيل. | ملف Playbook ومخرجات منزوعة الأسرار أو ملاحظات المراجع. | يستخدم modules معلنة بدل أوامر shell غير الضرورية، يحدد الحالة والهدف، يفحص بـ check mode حيث تدعمه modules، ويشرح لماذا لا ينتج التشغيل الثاني تغييرًا جديدًا. |
| جاهزية الإصدار | يراجع commit أو artifact وتعليمات التحقق والتراجع في تمرين مكتبي. | سجل قرار مختصر وقائمة تحقق مكتملة. | يتحقق من المصدر والبيئة والفحوص وخطة التراجع، ويوقف العملية عند اختلاف الإعدادات أو غياب دليل. |
| الاستجابة للحوادث | يصنف سيناريو افتراضيًا ويجمع الحد الأدنى من بيانات التشغيل. | تقرير محاكاة أو ملخص آمن. | يفصل بين الحقائق والفرضيات، يختار تصعيدًا مناسبًا، ولا يضع سجلات خامًا أو أسرارًا في التقرير. |
| الرجوع والتعلم | يحدد baseline ويتبع إجراء الرجوع في مراجعة مكتبية أو تمرين غير إنتاجي. | رابط التغيير أو سجل محاكاة مع خطوات التحقق. | لا يستخدم force-push ولا يتجاوز حماية الفرع، ويتحقق من المصدر والنتيجة بعد الرجوع. |

للمستوى L1 ينفذ المتدرب المهمة نفسها مع توجيه مباشر. وللمستوى L3 يراجع المقيم التصميم والحالات الحدية، ويشرح المخاطر، ويقدم ملاحظات قابلة للتنفيذ. لا تستبدل هذه المصفوفة فحوص CI أو الموافقات المطلوبة.

## قرارات التقييم

- **مجتاز:** ظهرت كل السلوكيات المطلوبة للمستوى المستهدف، مع دليل قابل للمراجعة.
- **يحتاج تدريبًا إضافيًا:** ظهرت فجوة محددة؛ يسجل تمرين إعادة التقييم بدل رفع المستوى بالتخمين.
- **لم يُلاحظ بعد:** لم يتوفر سيناريو أو دليل مناسب. لا تعني فشلًا ولا تُحسب نجاحًا.

للكفاءات التي تمس النشر أو الرجوع، يتطلب L2 تنفيذًا في سيناريو آمن مع تحقق مستقل من النتيجة. لا تستخدم بيئة الإنتاج لإثبات المهارة.
