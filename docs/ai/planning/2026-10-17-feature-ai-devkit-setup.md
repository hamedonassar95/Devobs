# خطة التنفيذ

## مراجعة الخطة

أُعيدت مواءمة الخطة بعد اكتمال مراجعة المتطلبات والتصميم. تغطي المهام التعديلات الناتجة عن المراجعات، ويرتبط التحقق بفحوص CLI وصياغة Bash ومراجعة إعداد المصدر.

## المهام

- [x] تمييز مخطط قالب `init --template` (`skill`) عن مخطط `.ai-devkit.json` المولّد (`name`).
- [x] تأجيل التخطيط إلى ما بعد مراجعة المتطلبات والتصميم، وإضافة بوابة ثابتة للمرحلة 4 في كاشف الاستئناف.
- [x] حل مسارات المستندات من جذر المستودع، ومطابقة المرحلة نسبةً إلى `paths.docs` مع استخدام `docs/ai` عند غيابها.
- [x] احتساب مربعات التخطيط الفعلية فقط، لا روابط Markdown التي تبدأ بـ`- [`.
- [x] استئناف worktree حسب الفرع المسجل فعليًا في `git worktree list --porcelain`.
- [x] حفظ ملاحظات التنفيذ عند إضافة قائمة تقدم المراحل، وإعادة فحص Phase 7 عند تعديل التنفيذ لإصلاح خلل اكتشفه Phase 8.
- [x] إعادة فتح التصميم والمراحل التابعة عندما تغيّر المتطلبات المقبولة أدلتها.
- [x] توثيق ترخيص Apache 2.0 برابط المصدر المثبت والتحقق من بيانات حزمة CLI.
- [x] مزامنة إرشادات Codex وClaude والتحقق من السكربتات والوثائق.

### أدلة التحقق

- نجح `npx --yes ai-devkit@0.70.1 lint` و`lint --feature ai-devkit-setup`.
- نجح تحليل JSON والتحقق من أن القالب يستخدم `skill` والإعداد المولّد `name` وفق [مرجع قالب التهيئة الرسمي](https://ai-devkit.com/docs/9-agent-setup/#template-field-reference).
- نجح `bash -n` للنسختين، وتطابقت سكربتات Codex وClaude، ونجح `git diff --check`.
- أعاد كاشف الحالة مستندات الميزة كافة من جذر المستودع عند تشغيله من `docs/`، وأظهر `9/9` مهام مكتملة، واقترح Phase 7 بعد إعادة فتح مرحلتي 7 و8 للتحقق من التعديل الحالي.
- تطابق ملف الرخصة المرفق بايتًا ببايت مع `LICENSE` في الالتزام المثبت، وأظهرت بيانات `ai-devkit@0.70.1` ترخيص `Apache-2.0`.

## التبعيات والمخاطر

- يحتاج تثبيت نسخة أحدث من المهارات إلى اتصال بالشبكة ومراجعة التغييرات قبل تحديث النسخ المحلية.
- لا تعتمد أوامر البناء والنشر الحالية على AI DevKit.
- لا تُمرر أسرار المشروع إلى المهارات أو إلى CI.

## الصيانة

عند إضافة مهارة، يجب أن يكون لها استخدام واضح في سير عمل Devobs، وأن تُضاف إلى الإعداد والنسخ الخاصة بالبيئتين معًا، ثم تُراجع نتائج فحص AI DevKit.
