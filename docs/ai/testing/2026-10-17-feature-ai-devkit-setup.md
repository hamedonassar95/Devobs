# التحقق والجودة

## الفحوص الآلية

- `python3 -B -m unittest tests.test_ai_devkit_status -v`: اختبارات الكاشف، وتشمل فشل lint غير المتوقع، والوثائق السبع المطلوبة، وJSON غير الصالح أو المتعارض، والتناقض في وجود الملفات أو مسارات الوثائق، وتطبيع أسماء الميزات، و`paths.docs` المخصص، والتشغيل من مجلد فرعي، وروابط Markdown في الخطة، ومخطط قالب التهيئة، ومراحل الدورة، وتطابق نسختي Codex وClaude.
- `npx --yes ai-devkit@0.70.1 lint` و`lint --feature ai-devkit-setup`: فحص الإعداد ووثائق الميزة وفق إصدار CLI المثبت.
- `python3 -B -m unittest discover -s tests -q`: مجموعة اختبارات Python للمستودع.
- `node --test tests/incident_guard.test.cjs`: اختبارات حارس الحوادث.
- `python3 -B scripts/check_site.py`: عقد الصفحة وفحص HTTP محلي.
- `python3 -B scripts/check_action_pins.py`: تثبيت إصدارات Actions في ملفات سير العمل والقوالب.
- سير ShellCheck التلقائي، وفحص ملفه عبر `actionlint`.
- `bash -n` لكل من سكربتي Codex وClaude، ثم مقارنة النسختين و`git diff --check`.

## النتائج المحلية

- نجحت اختبارات الكاشف الـ22 واختبارات Python الـ148 واختبارات Node الـ22.
- نجح فحص الموقع وفحص تثبيت Actions لـ29 ملفًا، كما اجتاز السكربتان ShellCheck ونجح فحص workflow عبر `actionlint`.
- نجح فحص AI DevKit الأساسي (7 فحوصات) وفحص الميزة (16 فحصًا)، بما يشمل الوثائق السبع والفرع ومسار worktree.
- اختُبر الكاشف مع CLI الحقيقي داخل مستودعين مؤقتين؛ وجّه نقص الوثائق إلى Phase 1 للمسار الافتراضي والمخصص عند تشغيله من مجلد فرعي.
- اكتمل `init --template` مع CLI حقيقي وسجل محلي مؤقت؛ أنشأ إعدادًا بـ19 مهارة تحمل `name` ونسخ المهارات كلها إلى مجلدي Codex وClaude.
- يستخدم القالب والإعداد سجل `codeaholicguy/ai-devkit` بمصدر Git صريح بدل الاعتماد على فهرس عام وقت التهيئة.
- احتسب كاشف الحالة مهام مربعات Markdown فقط، ولم يحتسب رابطًا عاديًا كمهمة تخطيط.
- لا يوفر CLI الإصدار `0.70.1` أمرًا لتسجيل المهام الدائم؛ يستأنف سير العمل من علامات المهام والمرحلة في المستندات.

لا يشغّل هذا الإعداد نماذج AI داخل GitHub Actions، ولا يغيّر بناء الموقع أو نشره على GitHub Pages. يعمل AI DevKit محليًا للمساهم، وتظل مراجعة الكود وقرارات الدمج بشرية.

## مراجعة يدوية

- التأكد من أن مجلدي المهارات يحتويان ملفات فعلية لا روابط رمزية إلى مسارات محلية.
- التأكد من وجود إشعار المصدر ونسخة الرخصة المرفقة.
- مراجعة أسماء المهارات مقابل `.ai-devkit.json` وأي تحديث للمهارات قبل اعتماده.
