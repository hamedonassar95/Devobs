# سياسة المحتوى والنطاق

## حدود النشر

المستودع `hamedonassar95/Devobs` عام؛ كل فرع وملف يُرفع إليه قابل للقراءة العامة. تعامل مع محتويات هذه الحزمة على هذا الأساس.

تحدد `.gitbook.yaml` و`SUMMARY.md` مجلدًا ضيقًا للحزمة. لا تضف `.gitbook.yaml` أو `SUMMARY.md` إلى جذر المستودع ضمن التحضير؛ الملفات الجذرية قد تغيّر قراءة GitBook للمحتوى الحالي كله.

## ما يدخل في الحزمة الحالية

تقتصر الحزمة الحالية على صفحات التحضير العامة المكتوبة لهذا الغرض:

| الملف | الغرض |
| --- | --- |
| `README.md` | يشرح النطاق والحالة ويربط بالوثائق العامة الحالية دون نسخها. |
| `SUMMARY.md` | فهرس الصفحات داخل هذا المجلد فقط. |
| `CONTENT_SCOPE.md` | يحدد قواعد اختيار المحتوى. |
| `INITIAL_SYNC_CHECKLIST.md` | يحدد خطوات مراجعة المزامنة المستقبلية. |

## ما يحتاج مراجعة مستقلة قبل إضافته

- أي صفحة أو مرفق من مساحة GitBook خاصة.
- محتوى يتضمن أسرارًا أو بيانات دخول أو قيم إعدادات أو روابط اتصال.
- سجلات الحوادث أو بيانات العملاء أو الأجهزة أو الموظفين.
- أسماء المستودعات الخاصة أو مساراتها ومعلوماتها التشغيلية غير المخصصة للنشر العام.
- وثائق داخلية أو مسودات لم يوافق مالكها على نشرها.
- أي ملف يكرر وثائق Devobs القائمة دون حاجة واضحة.

لم تُنسخ أي صفحة أو مرفق خاص من GitBook إلى هذه الحزمة. كما لم تُنسخ صفحات المستودع القائمة؛ الروابط في `README.md` تشير إلى مصادرها العامة الأصلية.

## فحص التكرار

قبل إضافة صفحة، قارن عنوانها ومحتواها بالوثائق القائمة، خصوصًا README ومركز الأتمتة وCI وDevSecOps والنشر ولوحة حالة AI. فضّل رابطًا إلى المصدر المعتمد على إنشاء نسخة مكررة، وسجّل مالك الصفحة وتاريخ مراجعتها وموافقتها على النشر.
